Политика конфиденциальности — Anekdots B

Последнее обновление: май 2026

1. Какие данные мы собираем

Приложение не собирает персональные данные пользователей, такие как имя, номер телефона, email или аккаунты.

Однако используются сторонние сервисы:

  • Firebase Firestore — загрузка анекдотов
  • Firebase Cloud Messaging — push-уведомления
  • Firebase Crashlytics — отчёты об ошибках

2. Crashlytics (отчёты об ошибках)

Firebase Crashlytics автоматически собирает техническую информацию об ошибках: состояние приложения, модель устройства, версию ОС и stack trace. Эти данные используются только для улучшения стабильности приложения.

3. Локальное хранение данных

Приложение хранит данные локально на устройстве пользователя: избранные анекдоты, настройки и кэшированные данные (Hive / SharedPreferences).

4. Уведомления

Используются Firebase Cloud Messaging и локальные уведомления. Персональные данные для уведомлений не используются. Уведомления служат только для напоминаний.

5. Использование интернета

Приложение использует интернет для загрузки анекдотов и работы Firebase-сервисов.

6. Реклама и монетизация

В будущем приложение может содержать рекламу. В этом случае политика конфиденциальности будет обновлена.
