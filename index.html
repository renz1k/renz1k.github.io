1. Какие данные мы собираем

Приложение не собирает персональные данные пользователей, такие как имя, номер телефона, email, адрес, местоположение или социальные аккаунты.

Что собирается автоматически:

  • Технические данные: модель устройства, версия ОС, версия приложения
  • ID устройства: анонимный идентификатор для Firebase
  • Данные об ошибках: информация о крашах (через Crashlytics)
  • Данные уведомлений: статус доставки push-уведомлений

✅ Мы НЕ собираем: Имена, номера, email, местоположение, истории браузера, контакты

2. Firebase сервисы

Приложение использует сервисы Google Firebase:

Сервис Назначение Данные
Firestore Загрузка анекдотов Анекдоты, ID устройства
Cloud Messaging Push-уведомления Токены устройств, статус доставки
Crashlytics Отчёты об ошибках Stack trace, версия ОС, модель устройства

💡 Google собирает эти данные в соответствии со своей политикой конфиденциальности. Мы не имеем доступа к вашему Google аккаунту.

3. Crashlytics (отчёты об ошибках)

Firebase Crashlytics автоматически собирает информацию об ошибках приложения для улучшения его стабильности.

Собираемая информация:

  • Stack trace (трассировка ошибки)
  • Версия ОС (Android/iOS)
  • Модель устройства
  • Версия приложения
  • Время ошибки
  • БЕЗ: Вашего контента, имён, email

⚠️ Важно: Crashlytics собирает данные ТОЛЬКО о ошибках. Если приложение работает без проблем, данные не отправляются.

4. Локальное хранение данных

Некоторые данные хранятся локально на вашем устройстве:

  • Избранные анекдоты — сохраняются в локальной БД (Hive)
  • Настройки приложения — выбор темы, язык и т.д. (SharedPreferences)
  • Кэш — загруженные анекдоты для быстрого доступа

✅ Все эти данные хранятся только на вашем устройстве и не отправляются на серверы.

5. Уведомления

Приложение использует Firebase Cloud Messaging (FCM) и локальные уведомления для отправки напоминаний.

Как отключить уведомления:

  • В приложении: Настройки → Уведомления → Отключить
  • На устройстве (Android): Параметры → Приложения → Анекдоты Б → Уведомления → Отключить
  • На устройстве (iOS): Параметры → Уведомления → Анекдоты Б → Отключить

Персональные данные не используются для отправки уведомлений. Они отправляются всем пользователям одинаково.

6. Использование интернета

Приложение подключается к интернету для:

  • Загрузки анекдотов из Firebase Firestore
  • Работы Firebase-сервисов (уведомления, ошибки)
  • Обновления данных приложения

Все соединения защищены HTTPS и зашифрованы.

7. Реклама и монетизация

Текущая версия приложения: без рекламы и платных функций.

В будущем: Если в приложение добавится реклама или платные функции, эта политика конфиденциальности будет обновлена. Вы будете уведомлены об изменениях.

💡 Рекламные сети могут собирать анонимные данные согласно политике Google

8. Права пользователя

Вы имеете право:

  • 📥 Доступ: Запросить информацию, какие данные о вас собраны
  • ✏️ Изменение: Обновить или исправить данные в приложении
  • 🗑️ Удаление: Удалить приложение и все локальные данные
  • 🚫 Отказ: Отключить уведомления и сбор данных об ошибках
  • 📤 Переносимость: Экспортировать избранное (вручную)

Как удалить данные:

  1. Откройте приложение и перейдите в Настройки
  2. Выберите "Сбросить данные" или "Очистить кэш"
  3. Удалите приложение со своего устройства
  4. Все локальные данные будут удалены
